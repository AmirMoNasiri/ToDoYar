# To Do Yar - Task Management Android App

An Android application for daily task management, helping users organize, prioritize, and track their activities with reminders and statistics.

## 📱 About the Project

This app allows users to:
- Authenticate and manage personal profiles
- Add, edit, and delete tasks
- Set priorities and categories for tasks
- Schedule due dates and reminders
- Filter and view tasks in different lists
- View charts and statistics of completed activities

## 🛠 Tech Stack

- **Language:** Kotlin
- **UI Toolkit:** Jetpack Compose
- **Architecture:** MVVM (Model-View-ViewModel)
- **Local Database:** Room
- **Dependency Injection:** Dagger Hilt
- **Version Control:** Git
